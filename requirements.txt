# Runtime dependencies for the Model Serving container.
#
# `deploy/log_and_deploy.py` passes this file to `mlflow.pyfunc.log_model(
# pip_requirements=...)`, so it is baked into the model artifact and is what the
# endpoint installs. `pyproject.toml` mirrors it for local development and CI;
# change both together.
#
# **Pinned exactly, on purpose.** With `>=` floors, two deploys a week apart can
# resolve to different builds of langgraph, langchain and psycopg with nothing
# recording the difference — the endpoint that passed evaluation and the
# endpoint serving traffic are then not demonstrably the same software. Exact
# pins make the model artifact reproducible and are what lets the supply-chain
# scan in CI be read as a statement about production rather than about whatever
# resolved that morning.
#
# To move a pin: raise it here and in pyproject.toml, run the suite, deploy to
# dev, and check the endpoint's build log for a resolution conflict before prod.
